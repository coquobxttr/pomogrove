## Getting Started

### Prerequisites

Have a package manager installed

  ```sh
  npm install npm@latest -g
  ```

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/github_username/repo_name.git
   ```
2. Install NPM packages
   ```sh
   npm install
   ```
3. Install tailwindcss for sveltekit by [following this tutorial](https://tailwindcss.com/docs/installation/framework-guides/sveltekit)
